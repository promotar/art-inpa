# Project Overview

Z4Rank is a custom modular platform built on top of Laravel. Laravel provides the backend framework, runtime, routing, configuration, dependency injection, and standard application structure.

The project will grow in phases. Phase 0 is limited to setup, documentation, Git tracking, and placeholder directories.

## Goals

- Keep Laravel standard and maintainable.
- Keep platform code separate from Laravel core.
- Prepare clear locations for platform core code and future functional modules.
- Keep each client installation independent at the beginning.

## Non-Goals for Phase 0

- No business features.
- No Filament installation.
- No authentication customization.
- No Blog, LMS, Store, or Exhibition implementation.
- No custom migrations.
