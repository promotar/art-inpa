# Deployment Guide

## Quick Setup on New Container

### Prerequisites
- Docker and Docker Compose installed
- Access to the repository and required environment variables

### Initial Setup Steps

1. **Clone the repository**
   ```bash
   git clone <repository-url> /path/to/art-inpa
   cd /path/to/art-inpa
   ```

2. **Configure environment**
   ```bash
   cp .env.example .env
   # Edit .env with your production database and settings
   nano .env
   ```

3. **Start containers**
   ```bash
   docker compose up -d --build
   ```

4. **First-time initialization**
   ```bash
   # The following happens automatically on container startup:
   # - PHP dependencies installed (composer install)
   # - Vite assets built (npm run build) - if not present
   # - Cache directories created
   
   # But you can manually trigger if needed:
   docker compose exec app php artisan key:generate
   docker compose exec app php artisan migrate --force
   ```

## Automatic Asset Build

The application automatically handles Vite asset building:

- **What happens**: On first container startup, the app checks for `/public/build/manifest.json`
- **If missing**: Automatically installs Node.js, npm dependencies, and builds assets
- **Why**: The `/public/build` directory is git-ignored because it's generated by `npm run build`

### If Assets Don't Build Automatically

Run manually:
```bash
docker compose exec app npm install
docker compose exec app npm run build
```

## Troubleshooting

### Error: "Vite manifest not found"
This occurs when assets haven't been built. Check logs:
```bash
docker compose logs app
```

If the build didn't complete, manually rebuild:
```bash
docker compose exec app npm run build
```

### Port Already in Use
Edit `docker-compose.yml` and change port bindings (e.g., `127.0.0.1:8089:80` for port 8089).

### Database Connection Fails
Verify `.env` has correct database credentials and MySQL container is running:
```bash
docker compose ps
```

### Memory Issues During Build
The Node.js build process needs sufficient memory. On limited environments:
```bash
# Check current limits
docker stats

# If needed, increase Docker memory allocation in Docker Desktop settings
```

## Production Considerations

1. **Environment**: Set `APP_ENV=production` in `.env`
2. **Debug**: Set `APP_DEBUG=false` in `.env`
3. **Cache**: Run `php artisan config:cache` after setup
4. **Assets**: Ensure `npm run build` completes successfully (check `public/build/` exists)

## Rollback

To restore previous state:
```bash
docker compose down
# Restore backup or previous git commit
git reset --hard <commit>
docker compose up -d --build
```
